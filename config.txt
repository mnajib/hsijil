# ============================================================
# config.txt  -  SATU-SATUNYA tempat kedudukan, saiz kertas dan font
#
# CARA BACA FAIL INI
#   [global]      nilai lalai untuk SEMUA template
#   [csv]         pemetaan nama lajur CSV asal kepada medan program
#                 (pilihan; tanpa [csv], lajur CSV mesti bernama: nama, nokp, template.
#                  lajur lain dalam CSV diabaikan)
#   [nama]        satu template. Nama sama dengan lajur 'template' dalam CSV
#   kunci = nilai satu tetapan. Teks selepas # ialah komen (diabaikan)
#   Nilai dalam seksyen template MENGGANTIKAN [global]
#
# SATU TEMPLATE = SATU SEKSYEN. Satu fail CSV boleh mengandungi baris
# untuk beberapa template; setiap nama template yang dipakai dalam CSV
# mesti ada seksyennya di sini. Satu PDF dijana untuk setiap template.
# Jangan tulis [t4] dua kali; letak semua kunci dalam SATU seksyen.
#
# UNIT
#   Jarak       : milimeter (mm), diukur dari SUDUT KIRI ATAS kertas
#   Saiz font   : point (pt)
#
# KUNCI YANG DIKENALI (kunci lain akan ditolak oleh program)
#   font       nama font, semak dengan:  fc-list : family | sort -u
#   tebal      ya | tidak
#   kertas_mm  lebar tinggi kertas.   A4 landskap = 297 210, A4 potret = 210 297
#
#   KOTAK - dua cara menulisnya (dalam SATU seksyen):
#   A. kotak_mm  x1 y1 x2 y2  (kiri atas kanan bawah ruang kosong pada sijil).
#                             kedudukan titik kiri-atas dan kedudukan titik kanan-bawah.
#   B. KOMBINASI (keempat-empat kunci diperlukan):
#      kotakHorizontalCenterPoint_mm  titik tengah mendatar kotak (mm dari kiri)
#      kotakWidth_mm                  lebar kotak (mm)
#      kotakPointAtas_mm              tepi atas (mm dari atas)
#      kotakPointBawah_mm             tepi bawah (mm dari atas)
#                             => kiri = tengah - lebar/2,  kanan = tengah + lebar/2
#   Aktifkan SALAH SATU. Jika kedua-duanya ditulis dalam seksyen yang sama,
#   KOMBINASI DIUTAMAKAN dan kotak_mm diabaikan (arahan 'semak' menandakan
#   sumber kotak: kotak_mm / kombinasi / kombinasi*  dengan * = kotak_mm diabaikan).
#   Seksyen template yang tiada kotak langsung mewarisi kotak dari [global].
#
#   nama_saiz  min maks     saiz font nama (nama panjang dikecilkan automatik)
#   kp_saiz    min maks     saiz font No. KP. PERATURAN: saiz No. KP TIDAK PERNAH
#                           lebih besar daripada saiz nama (diturunkan automatik).
#                           'maks' = saiz pilihan apabila nama cukup besar.
#   jarak_mm   jarak antara baris nama dan baris No. KP
#   offset_mm  x y          pembetulan printer (lihat README, bahagian Kalibrasi)
#
# NYAHAKTIFKAN template: letak # di hadapan SEMUA barisnya (termasuk [nama]).
# TAMBAH template baharu: salin satu seksyen, tukar nama + ukuran.
# ============================================================
